Reading the statuses — Needs Update: has a display that requires a transition and none of the replacement material has shipped yet. Partial: some but not all required replacement displays have shipped. Updated: every required replacement display has shipped since 5/1/2026. Up to Date: every display this dealer currently has is already the current generation — nothing owed. Unlisted: invoiced for these item classes but AR-Customers shows no display program on file. Do Not Update: manually excluded from tracking (e.g. inactive or non-paying accounts) — not counted in the progress bars.

Status override — click any status badge to manually set it, with an optional note. "Do Not Update" fully removes that dealer from the progress bars; overriding to any other status just corrects the badge shown without inventing shipment history. A 📌 marks a person's manual override; a 🔒 marks an automatic flag (see below). Hover either to see what the automatic status would have been. Overrides are shared, same as scheduled dates.

Automatic "Do Not Update" flag — any customer whose name ends in -COLL (a credit-risk/collections account) is automatically flagged Do Not Update and excluded from the progress bars. This is a default, not a lock — click the badge to manually override it back to a tracked status if the credit issue resolves.

Current Display sales indicator — each chip shows a colored dot for that collection's trailing-12-month sales at this customer: green (>$5,000), yellow ($0–$5,000), red ($0). The idea: if a customer isn't buying a collection at all, it may not be worth spending display budget updating them to its replacement. Hover a chip for the exact dollar figure.

Scheduled column — for each display still owed, shows an open Sales Order (SO# & date) if one exists, or lets you click to note an expected date manually if no SO has been entered yet. Manual dates are shared — anyone opening this page sees the same notes, stored via the Worker. Click the pencil to edit a note or the × to remove it.

Click any row to expand the invoice and open-order line detail. Lines highlighted green count toward a required update; the rest are other samples/marketing collateral invoiced in the same window.

Business rules (which display replaces which, and which SKU counts toward which display) live in asf-display-tracker-mapping.json — edit that file to change the logic without touching this page.
